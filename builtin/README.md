# Wbudowane zadania Sakura Task v1

18 deklaracji projektowych katalogu. Każda używa tego samego schema i walidatora co zadanie własne. Nie zawierają kodu wykonawczego. Nie są aktywne ani zatwierdzone. Metadane indeksu nie nadają uprawnień, klasy ryzyka pochodzą z przyszłego zaufanego rejestru ActionContract. Pola i identyfikatory parametrów są propozycją do zatwierdzenia w kontraktach akcji. Brak zgodnego adaptera oznacza blokadę, nie fallback. Publikacja wersji builtin następuje wraz z podpisanym release; użytkownik może utworzyć kopię z nowym ID. Zobacz docs/14-workflow-engine.md.
